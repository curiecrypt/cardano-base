## Test vectors for Falcon-det512
Known-answer tests for `FalconDet512DSIGN`, taken unmodified from the deterministic Falcon
implementation vendored in `cbits/falcon`:
- Source: [algorand/falcon](https://github.com/algorand/falcon) at commit
  `19f185792c39326bebc173b2a100c2c247423be3`, file `tests/test_deterministic512_kat.h`,
  array `FALCON_DET512_KAT_CT`.
- License: MIT, see `NOTICE`.

### `test_vectors/kat_ct`
32 signatures in the CT format (770 bytes), hex encoded, one per line. Line `i` (counting
from 0) is the signature of:
- the key generated by `falcon_det512_keygen` from a SHAKE256 PRNG seeded with the 8 bytes
  `key-%04d` (`key-0000`, `key-0001`, ...);
- the message made of the first `i` bytes of SHAKE256 of `msg-%04d` (`msg-0000`, ...), so
  the message of line 0 is empty.

This is how Algorand's `tests/test_deterministic512.c` builds its test cases.

The file was extracted with:
```
curl -sSfL https://raw.githubusercontent.com/algorand/falcon/19f185792c39326bebc173b2a100c2c247423be3/tests/test_deterministic512_kat.h \
  | awk '/FALCON_DET512_KAT_CT/{f=1;next} f&&/^};/{exit} f' | tr -d '\t\r",' > test_vectors/kat_ct
```
